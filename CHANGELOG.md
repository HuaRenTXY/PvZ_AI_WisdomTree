# Changelog

## 0.1.0 — 2026-10-28

- Forked from PvZ-Portable.
- Added DeepSeek-backed Wisdom Tree:
  - fertilize the Zen Garden tree to open a prompt
  - immediate `思考中…` speech bubble
  - AI reply replaces the tree speech and stays open
  - Chinese text via GDI/PvZ2 with YaHei fallback
- Added DeepSeek API key field to Options.
- Added warning dialogs for missing/invalid API key.
- Added built-in perfect save for testing.
- Default windowed 800x600 launch.
- Added LGPL source distribution files: `NOTICE.md`, `AI_CHANGES.md`, `BUILDING-WINDOWS.md`, `PvZAI.ini.example`.
